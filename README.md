# TD VI — Trabajo Práctico N°2

Este repositorio contiene todo el código fuente correspondiente al *Trabajo Práctico N°2* de la materia de *TD VI: Inteligencia Artificial*. 

## Estructura del repositorio

```text
.
├── dataset/                           # Datasets: train.csv, test.csv
├── .gitignore
├── README.md
├── TD_VI_TP2_consigna.pdf
├── TD_VI_TP2_informe.pdf              # Informe sobre el análisis y la toma de decisiones
├── ml-lifecycle-analysis.ipynb        # Jupyter Notebook (TP)
└── requirements.txt                   # Dependencias del proyecto
```

## Replicabilidad del entorno

El proyecto utiliza **Python** y Jupyter Notebooks.

Para instalar las dependencias utilizando un entorno virtual:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
